# RAG 入门：让回答找到参考资料

检索增强生成把资料检索与模型生成连接起来：先寻找与问题有关的内容，再把这些内容作为上下文提供给模型。

> 示例笔记，可以替换成自己的学习记录。

## 两条主要流程

建立知识库时，通常要经历文档解析、内容切分、向量化与索引构建。回答问题时，则经历查询、检索、上下文组织与生成。

```text
文档 → 解析与切分 → 向量化 → 建立索引

问题 → 检索相关片段 → 组织上下文 → 生成回答
```

## 切分不是越小越好

片段太短可能丢失上下文，太长则可能引入无关内容。标题、段落边界和文档结构，都可以作为切分时的参考。

## 检索结果需要检查

调试时先观察模型收到的资料：

1. 片段是否真的与问题相关？
2. 是否遗漏了关键定义或前提？
3. 相近概念是否混在一起？
4. 最终回答能否对应到来源？

### 没找到资料时

检索增强并不保证回答正确。资料不足时，应明确表达不确定性，而不是把生成的内容当作已有证据。
