# CSS Grid：让布局跟随屏幕变化

响应式布局的重点，是让同一份内容在不同宽度下仍然便于阅读。网格布局可以用很少的规则表达列宽、间距和排列方式。

> 示例笔记，可以替换成自己的学习记录。

## 先定义两列布局

```css
.layout {
  display: grid;
  grid-template-columns: 220px minmax(0, 1fr);
  gap: 32px;
}
```

第一列用于导航，第二列容纳正文。`minmax(0, 1fr)` 允许内容列收缩，长代码块则在自身容器中横向滚动。

## 小屏幕改成单列

```css
@media (max-width: 800px) {
  .layout {
    grid-template-columns: minmax(0, 1fr);
  }
}
```

### 检查阅读体验

- 正文是否仍然足够清晰？
- 导航能否轻松展开和收起？
- 图片是否超出了容器？
- 代码与表格能否独立滚动？

布局完成后，还需要结合真实内容检查长标题、图片和表格。
