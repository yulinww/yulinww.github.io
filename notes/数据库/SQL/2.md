# 分组与聚合：WHERE / HAVING 有什么区别？

当问题从“有哪些记录”变成“每类记录有多少”时，就需要考虑分组和聚合。区分分组前的筛选与分组后的筛选，是理解这类查询的关键。

## GROUP BY 与 COUNT

```sql
SELECT city, COUNT(*) AS student_count
FROM students
GROUP BY city;
```

这里先按城市分组，再统计每个分组中的记录条数。

## WHERE 与 HAVING

```sql
SELECT city, COUNT(*) AS student_count
FROM students
WHERE age >= 22
GROUP BY city
HAVING COUNT(*) >= 2;
```

- `WHERE` 在分组前筛选原始记录。
- `HAVING` 在分组后筛选分组结果。
- `COUNT(*)` 统计行数；`COUNT(列名)` 只统计该列不为 `NULL` 的记录。

### 一个检查思路

遇到复杂查询时，可以先去掉 `HAVING`，观察每组的中间结果，再加回分组筛选条件。
