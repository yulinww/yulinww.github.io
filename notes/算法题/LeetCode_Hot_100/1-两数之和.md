# 1-两数之和

> 题目类型：哈希表
>
> 难度：简单

## 题目

给定一个整数数组`nums`和一个整数目标值`target`，请你在该数组中找出**和为目标值**`target`的那**两个**整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

你可以按任意顺序返回答案。



> **示例1：**
>
> 输入：nums = [2,7,11,15], target = 9
>
> 输出：[0,1]
>
> 解释：因为 nums[0] + nums[1] == 9 ，返回 [0, 1] 。
>
> **示例2：**
>
> 输入：nums = [3,2,4], target = 6
>
> 输出：[1,2]
>
> **示例3：**
>
> 输入：nums = [3,3], target = 6
>
> 输出：[0,1]



> **提示：**
>
> - 2 <= nums.length <= $10^4$
> - $-10^9$ <= nums[i] <= $10^9$
> - $-10^9$ <= target <= $10^9$
> - **只会存在一个有效答案**



## 题解

题解，哈希表

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        seen = {}
        for i, x in enumerate(nums):
            need = target - x
            if need in seen:
                return [seen[need], i]
            seen[x] = i
        return []
```



## 理解

### 以一个示例进行逐步推演

`nums = [2, 7, 11, 15], target = 9`

初始：

```python
seen = {}
```

第一轮for循环：

```python
i = 0
x = 2
need = 9 - 2 = 7
```

判断

```python
need in seen  # 7 in {} ?
```

结果为False。

所以不返回，执行

```python
seen[2] = 0
```

**此时字典变成：**

```python
seen = {
    2: 0
}
```

要正确理解Python中字典的键值对，不要搞错。

键2表示数组里的值2，值0表示它的下标是0。

---

第二轮for循环：

```python
i = 1
x = 7
need = 9 - 7 = 2
```

判断：

```python
need in seen # 2 in {2: 0} ?
```

这里检查的是：字典的键里有没有`2`。

显然有。

所以条件成立，返回

```python
[seen[2], 1]
```

也就是

```python
[0, 1]
```



> 容易误解的点：
>
> - “因为seen集合里更新了一个元素0，所以显然2不在这个集合里面”
>
> 这是把`seen[2]=0`理解成了“把0放进集合”。
>
> 实际上它是`字典[键] = 值`



## 哈希表

哈希表（Hash Table）是一种抽象的数据结构，它解决的核心问题是：

> 如何根据一个键，快速找到对应的值。

它背后的思想是：通过一个哈希函数，把键转换成一个整数索引，然后尽量直接定位到存储位置，从而实现`O(1)`的平均查找时间。

所以：

- 哈希表是逻辑概念，它不规定具体代码怎么写
- Python的字典（dict）就是哈希表的一种非常成熟的具体实现



另外：

- 在Python字典中，键是唯一的。如果给同一个键多次赋值，后面的值会覆盖前面的值。
