# 20-有效的括号

> 题目类型：栈
>
> 难度：简单

## 题目

给定一个只包括`‘(’`，`‘)’`，`‘{’`，`‘}’`，`‘[’`，`‘]’`的字符串`s`，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个相应的相同类型的左括号。

> 示例 1：
>
> 输入：s = "()"
>
> 输出：true
>

> 示例 2：
>
> 输入：s = "()[]{}"
>
> 输出：true
>

> 示例 3：
>
> 输入：s = "(]"
>
> 输出：false
>

> 示例 4：
>
> 输入：s = "([])"
>
> 输出：true
>

> 示例 5：
>
> 输入：s = "([)]"
>
> 输出：false

提示：

- 1 <= s.length <= $10^4$

- `s` 仅由括号 `'()[]{}'` 组成



## 题解

栈匹配括号。

最近打开的括号必须最先闭合。

```python
class Solution:
    def isValid(self, s: str) -> bool:
        match = {')': '(', ']': '[', '}': '{'}
        stack = []
        for ch in s:
            if ch in match.values():
                stack.append(ch)
            else:  # 这里直接用elif也行，注意Python里没有else if
                if not stack or stack.pop() != match[ch]:
                    return False
        return not stack
```



## 理解

比如：`“([])”`。

先打开`(`，再打开`[`，那么必须先关闭`]`，最后关闭`)`。

即：**最近出现、还没匹配的左括号，必须最先闭合。**

这正好符合栈的“后进先出”，所以用栈来解决。

**1.栈里存什么**

只存**还没被匹配的左括号。**

从左到右遍历字符串：

- 遇到左括号：放入栈中，等它的右括号。
- 遇到右括号：检查栈顶的左括号是否与它匹配。匹配就移除，否则返回false。
- 遍历结束：栈为空，说明全部匹配成功；还有剩余，说明有左括号没有闭合。

**2.代码实现**

`match`是`右括号->对应左括号`的映射，例如：

```python
match[']']  # '['
```

`match.values()`：由于match是一个Python字典（dict），每项由键（key）和值（value）组成。

**字典有三个常用的配套方法：**

| 方法             | 含义           |
| ---------------- | -------------- |
| `match.keys()`   | 获取所有键     |
| `match.values()` | 获取所有值     |
| `match.items()`  | 获取所有键值对 |

所以：

```python
if ch in match.values():
    stack.append(ch)
```

表示：如果当前字符是左括号，就入栈。Python列表的末尾就是这里的栈顶。

遇到右括号时：

```python
if not stack or stack.pop() != match[ch]:
    return False
```

它检查两种错误：

- 栈为空：右括号出现了，却没有左括号可以配对。
- 栈顶不匹配：`pop()`取出并删除栈顶元素，再和当前右括号需要的左括号比较。

**列表常见用法：**

| 方法                 | 含义                                                         |
| -------------------- | ------------------------------------------------------------ |
| `stack.append(x)`    | 在末尾添加一个元素                                           |
| `stack.pop()`        | 删除并返回末尾元素。也可以指定下标，如pop(1)，删除并返回下标为1的元素 |
| `stack[-1]`          | 只查看末尾元素，不删除                                       |
| `len(stack)`         | 获取元素数量                                                 |
| `extend(可迭代对象)` | 将其中的元素逐个添加到末尾                                   |
| `insert(下标,元素)`  | 在指定位置插入元素                                           |
| `remove(元素)`       | 删除第一个等于`元素`的元素；找不到会报错                     |
| `clear()`            | 清空列表                                                     |
| `index(元素)`        | 返回第一个匹配`元素`的下标；找不到会报错                     |
| `count(元素)`        | 统计该元素出现的个数                                         |
| `reverse()`          | 原地反转元素顺序                                             |
| `sort()`             | 原地排序，默认升序                                           |

最后

```python
return not stack
```

表示栈为空时返回True，否则返回False。



## 复杂度

- 时间复杂度：`O(n)`

遍历长度为`n`的字符串，每个字符串最多入栈、出栈各一次。`append()`和末尾`pop()`的时间都是`O(1)`。`match.values()`也是`O(1)`。

- 空间复杂度：`O(n)`

最坏情况下字符串全是左括号，栈需要存储`n`个元素。字典`match`的大小是常量，只占`O(1)`空间。（无论字符串`s`有多长，即使有100万个字符，字典中也只有三对键值对）
